## Actions à réaliser par vous

Pour finaliser la publication sur GitHub, vous devez suivre les étapes décrites dans le fichier GITHUB_INSTRUCTIONS.md :

1. 📌 **Créer un dépôt GitHub** nommé "GameForge" sur votre compte GitHub

2. 📌 **Connecter votre dépôt local au dépôt GitHub** en exécutant les commandes suivantes :
   ```bash
   git remote add origin https://github.com/Mohamed-Amine0/GameForge.git
   git branch -M main
   git push -u origin main
   ```

3. 📌 **Vérifier que tout a bien été publié** en consultant votre dépôt GitHub
